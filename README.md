# Tempoa

**Nunca mais te esqueças de uma tarefa, compromisso ou atividade.**

O Tempoa é uma aplicação para o **Windows** que te ajuda a organizar o teu dia e a lembrar-te de
cada coisa no momento certo — com alertas que realmente se fazem notar.

## O que é este projeto

O Tempoa é uma ferramenta simples de agendamento de tarefas. Planeias um compromisso, uma tarefa
ou uma atividade, defines a hora, e o Tempoa trata do resto: avisa-te na altura certa, da forma
mais difícil de ignorar.

## Objectivo

Não perder compromissos, medicamentos, reuniões ou tarefas importantes. Em vez de uma lista que se
esquece na gaveta, o Tempoa garante que o alerta chega até ti — mesmo que a aplicação esteja em
segundo plano ou a janela fechada.

## Como funciona

1. **Cria a tua tarefa** — dá-lhe um nome, escolhe o dia e a hora. Podes adicionar uma nota e,
   se quiseres, um **alerta de repetição** (5, 10, 15, 30 ou 60 minutos) e um **lembrete** antes
   ou depois da hora marcada.
2. **No momento certo, o Tempoa avisa-te:**
   - **Alerta prioritário** — um ecrã completo, sempre por cima de tudo, com som. Repete até
     dispensares ou concluíres a tarefa.
   - **Lembretes** — pequenas notificações no canto inferior direito, empilháveis e fecháveis,
     para avisos mais discretos.
3. **O teu dia num só ecrã** — as tarefas do dia ordenadas por hora, com destaque para o próximo
   compromisso, e um calendário mensal para navegares pelos dias.
4. **Corre em segundo plano** — fechar a janela não fecha o Tempoa: ele continua na **bandeja do
   Windows** e os alertas continuam a funcionar. Podes ainda escolher iniciar o Tempoa com o
   Windows nas Definições.

Os teus dados ficam guardados localmente no teu computador.

## Descarregar e instalar

As versões oficiais estão disponíveis em **GitHub Releases**:

👉 [Descarregar o Tempoa](https://github.com/PEAL-26/tempoa/releases)

1. Na página de Releases, escolhe a versão mais recente.
2. Em *Assets*, descarrega o ficheiro **`Tempoa_..._x64-setup.exe`**.
3. Executa o ficheiro e segue a instalação (tudo pronto em segundos).
4. O Windows SmartScreen pode pedir confirmação — escolhe *Mais informações* → *Executar assim mesmo*.

Requisitos: **Windows 10 ou 11**.

## Contribuir e enviar issues

Encontraste um problema, algo não funciona como esperado, ou tens uma ideia para melhorar o Tempoa?

- **Reportar um bug ou sugerir uma ideia** → abre uma *issue* em
  [Issues](https://github.com/PEAL-26/tempoa/issues). Descreve o que aconteceu, o que esperavas
  que acontecesse e (se possível) os passos para reproduzir.
- **Contribuir com código** → faz um *fork* do projeto, implementa as tuas alterações e envia um
  *pull request*. Não te esqueças de referenciar a *issue* relacionada, se existir.

Este projeto é público e aberto — toda a ajuda é bem-vinda.
